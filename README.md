# MediTrack - IoT Smart Medicine Transport System

IoT based system to prevent medicine theft, spoilage and tamper during transport.

## Hardware Used
- Arduino Uno
- DHT22 Temperature Sensor
- HX711 Load Cell (Weight)
- HC-SR04 Ultrasonic Sensor
- Buzzer + LED

## Features
- Theft detection via weight change
- Temperature monitoring >30C alert
- Movement start detection
- Buzzer alert system
